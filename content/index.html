📖 应用简介

Concourse 是一个基于容器的自动化系统，使用 Go 语言编写，主要用于持续集成（CI）和持续交付（CD）。它通过可扩展的流水线（Pipeline）模型来定义和运行各种自动化任务，从最简单的构建脚本到复杂的多阶段部署流程。


Concourse 的设计理念强调：幂等性、不可变性、声明式配置、无状态工作节点和可重现的构建，确保 CI/CD 流程的可靠性和一致性。

安装 Fly CLI 工具

  1. 访问 Concourse Web UI
  2. 点击右上角下载对应系统的 fly CLI 工具
  3. 将下载的文件放入系统 PATH 中并赋予执行权限

创建你的第一个流水线

1. 创建流水线配置文件 pipeline.yml：

jobs:
- name: hello-world
  plan:
  - task: say-hello
    config:
      platform: linux
      image_resource:
        type: registry-image
        source:
          repository: ghcr.io/hlesey/busybox
      run:
        path: sh
        args:
        - -c
        - |
          echo "Hello, Concourse!"
          echo "Hello, LazyCAT!"

2. 登录到 Concourse：

fly -t tutorial login -c https://your-app-url -u admin -p admin

3. 设置流水线：

fly -t tutorial set-pipeline -p my-first-pipeline -c pipeline.yml

4. 启用流水线：

fly -t tutorial unpause-pipeline -p my-first-pipeline

5. 触发流水线执行：

fly -t tutorial trigger-job -j my-first-pipeline/hello-world --watch

⚙️ 配置说明

环境变量配置

Concourse 通过环境变量进行配置。在 Lazycat 平台中，你可以在应用设置中修改以下环境变量：

变量名 默认值 说明
CONCOURSE_EXTERNAL_URL 自动配置 外部访问地址，平台会自动设置
CONCOURSE_ADD_LOCAL_USER admin:admin 本地用户凭证（格式：用户名:密码）
CONCOURSE_POSTGRES_HOST concourse-db PostgreSQL 数据库主机地址
CONCOURSE_WORKER_RUNTIME containerd Worker 运行时引擎

系统要求

  • 内存：建议至少 2GB
  • 存储：数据库数据会持久化存储
  • 网络：需要访问容器镜像仓库

📖 Introduction

Concourse is a container-based automation system written in Go, primarily used for Continuous Integration (CI) and Continuous Delivery (CD). It uses an extensible Pipeline model to define and run various automation tasks, from simple build scripts to complex multi-stage deployment processes.


Concourse's design philosophy emphasizes: idempotency, immutability, declarative configuration, stateless workers, and reproducible builds, ensuring reliability and consistency in CI/CD processes.

✨ Main Features

🔄 Pipeline-as-Code

All workflows defined in YAML files, making pipelines version-controlled and easy to share

🐳 Container-First

Native container support, all tasks run inside Docker images ensuring environment consistency

📦 Resource Abstraction

Unified resource interface supporting Git, S3, Docker images, time triggers, and more

🔧 Powerful Debugging Tools

Built-in fly execute for local task execution and fly intercept for container debugging

♻️ Idempotency Guarantee

Tasks designed to be ephemeral and idempotent, ensuring build reproducibility

🌐 Web UI

Intuitive visual interface for real-time pipeline status and task execution monitoring

🔐 Access Control

Multi-team management support with fine-grained permission control

📊 Parallel Execution

Automatic parallelization of independent tasks for improved build efficiency

⚙️ Configuration

Environment Variables

Concourse is configured through environment variables. On the Lazycat platform, you can modify the following environment variables in the application settings:

Variable Name Default Value Description
CONCOURSE_EXTERNAL_URL Auto-configured External access URL, automatically set by platform
CONCOURSE_ADD_LOCAL_USER admin:admin Local user credentials (format: username:password)
CONCOURSE_POSTGRES_HOST concourse-db PostgreSQL database host address
CONCOURSE_WORKER_RUNTIME containerd Worker runtime engine

System Requirements

  • Memory: At least 2GB recommended
  • Storage: Database data is persisted
  • Network: Requires access to container image registries
